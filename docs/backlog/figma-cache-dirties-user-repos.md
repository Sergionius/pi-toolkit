# figma-кэш пачкает рабочее дерево пользовательских репозиториев

Кэш пишется в `<repo>/.pi/figma-cache/...`. Если у проекта нет `.pi/` в `.gitignore`, появление кэша делает дерево dirty — что особенно больно рядом с Ralphex preflight, запрещающим незакоммиченные изменения кроме плана. Исправление: писать в tmpdir (с сохранением кэша между запусками) или документировать требование игнорировать `.pi/`.
