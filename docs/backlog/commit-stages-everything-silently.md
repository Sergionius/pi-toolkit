# /commit молча стейджит всё дерево

`git add .` безусловно захватывает любые посторонние untracked-файлы. Это заявленный дизайн команды, но предупреждение при заметном числе новых untracked-файлов (или вывод списка захваченного в notify) снизит риск случайного коммита мусора.
