# plan-state без блокировки и с неограниченным ростом

`loadStore`/`saveStore` — синхронное чтение/запись глобального JSON на каждый `input`/`tool_call`; нет lock, поэтому две параллельные pi-сессии могут затереть файл друг друга, а записи `planModes` по сессиям никогда не удаляются. Исправление: атомарная запись + простая блокировка (по образцу codex-auth) и чистка записей старше N дней.
