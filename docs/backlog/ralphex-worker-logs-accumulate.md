# диагностические логи ralphex worker накапливаются навсегда

Каждый вызов `runPiWorker` (включая успешные попытки exec/plan/review) создаёт `mkdtempSync` каталог `ralphex-worker-*` в tmpdir с `attempt.json`, содержащим полный stdout/stderr. Удаления или ретенции нет: `/tmp` растёт бесконечно, а логи содержат потенциально чувствительный вывод. Исправление: удалять каталог при успешной попытке (оставлять только ошибки) и/или чистить каталоги старше N дней при следующем запуске.
